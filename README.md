### ✨ អ្វីដែលថ្មីក្នុងកំណែ v1.0.1 (What's New):
1. **Resolution Auto = 720p (HD):** ស្វ័យប្រវត្តិកំណត់កម្រិត 720p HD ជាលំនាំដើម ទាញយកលឿនជាងមុន **3x - 5x** និងសន្សំសំចៃទំហំ Hard Drive។
2. **Fixed Download Queue:** ជួសជុលបញ្ហា Queue កកស្ទះ និងកែតម្រូវការបង្ហាញចំនួនភាគឱ្យពេញលេញ (Full Ep - e.g. 61/61)។
3. **Auto-Update System:** បន្ថែមប្រព័ន្ធធ្វើបច្ចុប្បន្នភាពស្វ័យប្រវត្តិតាមរយៈប៊ូតុង Update ដោយផ្ទាល់លើរបារកម្មវិធី (Navbar) ដោយមិនចាំបាច់ផ្ញើ File ម្ដងមួយៗ។
4. **Offline H.264 Playback:** វីដេអូទាញយករួចអាចចាក់ Play បានភ្លាមៗលើកុំព្យូទ័រ Windows ដោយគ្មានបញ្ហាអេក្រង់ខ្មៅ ឬលឺតែសម្លេង។

## 🔄 របៀប Update ស្វ័យប្រវត្តិ (How Auto-Update Works)
នៅពេល Admin បញ្ចេញកំណែថ្មី អ្នកប្រើប្រាស់គ្រាន់តែ៖
1. ចុចលើប៊ូតុង icon **Update (🚀)** នៅលើ Navbar ខាងស្តាំរូបមនុស្ស (👤)
2. ផ្ទាំង Update Modal នឹងបង្ហាញព័ត៌មានលម្អិតនៃកំណែថ្មី
3. ចុចប៊ូតុង **"ធ្វើបច្ចុប្បន្នភាពឥឡូវនេះ (Update Now)"**
4. កម្មវិធីនឹងទាញយក និងដំឡើងដោយស្វ័យប្រវត្តិ រួចបើកដំណើរការឡើងវិញភ្លាមៗ!
